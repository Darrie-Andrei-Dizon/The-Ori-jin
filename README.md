# The-Ori-jin

## Backend

Orders, menu and tracking run on Google Sheets + Google Apps Script.

- `backend/Code.gs` – Apps Script backend (paste into the Sheet's Apps Script editor)
- `backend/README.md` – setup steps and front-end integration guide
- `api.js` – front-end helper (`OrijinAPI`, `Cart`); set `ORIJIN_API` to the deployed `/exec` URL
